# Contribuir a ReaSet / Contributing to ReaSet

*(English below)*

## Español

Las contribuciones son bienvenidas: reportes de bug, ideas, y parches.

### Acuerdo de contribución (CLA)

ReaSet se distribuye bajo una licencia propietaria de uso gratuito
(ver [`LICENSE`](./LICENSE)), y parte de este código también se usa en
**ReaSet Pro**, un producto comercial.

Para que eso siga siendo posible, **al enviar un pull request confirmás que**:

1. Sos el autor de lo que enviás, o tenés derecho a enviarlo.
2. **Le otorgás al autor de ReaSet una licencia perpetua, mundial, irrevocable
   y libre de regalías** para usar, modificar, sublicenciar y distribuir tu
   contribución, **incluso dentro de productos comerciales de código cerrado**.
3. Conservás tu propio derecho de autor sobre tu contribución y podés usarla
   como quieras en otros lados.

No hace falta firmar nada aparte: abrir el pull request alcanza. Si no estás de
acuerdo con esto, abrí un issue describiendo la idea en vez de mandar código —
también sirve, y mucho.

### Antes de mandar un pull request

- ReaSet corre en escenario. Un bug acá no es un ticket, es un show arruinado.
  Probá tu cambio con REAPER abierto antes de mandarlo.
- `ReaSet.html` es un solo archivo grande. Cambios acotados y bien comentados
  se revisan; refactors masivos, difícilmente.
- Explicá el **porqué** en el mensaje del commit, no solo el qué. Este repo
  documenta razones a propósito.

## English

Contributions are welcome: bug reports, ideas, and patches.

### Contributor Licence Agreement (CLA)

ReaSet ships under a proprietary, free-to-use licence (see
[`LICENSE`](./LICENSE)), and some of this code is also used in **ReaSet Pro**,
a commercial product.

To keep that possible, **by submitting a pull request you confirm that**:

1. You wrote what you are submitting, or have the right to submit it.
2. **You grant the author of ReaSet a perpetual, worldwide, irrevocable,
   royalty-free licence** to use, modify, sublicense and distribute your
   contribution, **including inside closed-source commercial products**.
3. You keep your own copyright in your contribution and may use it however you
   like elsewhere.

Nothing separate to sign: opening the pull request is enough. If you would
rather not agree to this, open an issue describing the idea instead of sending
code — that helps too, a lot.

### Before opening a pull request

- ReaSet runs on stage. A bug here is not a ticket, it is a ruined show. Test
  your change with REAPER open before sending it.
- `ReaSet.html` is one large file. Focused, well-commented changes get
  reviewed; sweeping refactors rarely do.
- Explain the **why** in the commit message, not just the what. This repo
  documents reasons on purpose.
